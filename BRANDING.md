# Public build identity

This repository builds a complete local desktop application without private
files or hosted-service configuration.

- Product name: `Zinuto Core`
- Bundle ID: `org.zinuto.core`
- Logo source: `config/brand/assets/zinuto-core-logo.png`
- Official hosted services: none
- Outbound access: user-triggered open-source market-data connectors only
- Account, support, presence, notice, telemetry, and update capabilities: none
- Signing and store identity: distributor-owned

Anyone distributing a modified build must replace the product name, bundle
identifier, logo, signing identity, and package metadata with values they
control. Branding changes must not add or remove local capabilities.
